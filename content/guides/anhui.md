# 先在一分一段表里找到自己

打开安徽省教育招生考试院公布的当年一分一段表。确认年份、科类和表名，再找到自己的分数。如果表中同时列出「本段人数」和「累计人数」，前者是同分考生的人数，后者含更高分和本分数段的人数。记录原表的列名和数值，保留同分区间的信息。

[安徽省教育招生考试院](https://www.ahzsks.cn/)

# 把往年的记录放在同一张表里

打开北科大的历年录取查询，选择安徽和要查的年份。抄下页面实际提供的省份、科类、批次、专业或专业组、录取分数。只有分数时，可以回到**对应年份、对应科类**的一分一段表查位次范围。年份之间科类划分或投档方式发生变化的记录，要单独标出来。

比如，你关心材料类，手里却只有某年全校最低录取分。先在表里把这条记录标成「学校」，再找材料类同年的专业数据。查不到就留空，学校最低分不能用来回答「当年这个专业录了多少分」。

[北科大历年录取查询](https://zhaoshengyunzhi.ustb.edu.cn/zsw/lnfs.html)

# 回到今年的计划，逐项核对

查北科大在皖招生计划时，把想报的专业逐个记下，核对选考科目要求、招生人数和专业名称。再用安徽当年的正式报考材料核对院校专业组及专业代码。计划表上的人数和往年实际录取人数分列记录，便于回头复查。

[北科大分省招生计划](https://zhaoshengyunzhi.ustb.edu.cn/zsw/zsjh.html)

# 留下一份能复查的记录

下载表格，每条数据填一行，最后两列留给原始链接和自己的疑问。带着「这两年同一专业的选科要求有没有变」这样的问题去听宣讲，更容易得到具体回答。
